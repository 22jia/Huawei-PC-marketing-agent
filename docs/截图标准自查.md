# 图文软文 Agent 标准自查

## 来源口径

按参赛方与主办方沟通后的明确要求，本地 `华为PC全板块深度知识库_v7` 是认可来源，不要求在线访问 ima。产品事实及配图先读本地资料，动态信息按配置补充华为商城；不以 ima 配额作为创作前提。

## 截图要求与工程实现

| 标准 | 当前实现 | 验收位置 |
| --- | --- | --- |
| 八模块系统提示词 | 角色、场景、平台、知识、图片、生成、核验、合规；由运行时代码读取，非单独的展示稿 | `services/api/prompts/marketing-system.md`、`services/api/src/clients/llmClient.cjs` |
| 自研 Agent 执行 | 模型判断意图、更新任务、规划检索；本地检索与型号澄清；模型策划、写作、审稿；失败最多重写一次 | `services/api/src/agent/taskAgent.cjs` |
| 场景实质差异 | 策划返回读者困扰、购买阶段、切入点、具体事实引用；审稿检查具体任务与证据支持 | `content_strategy`、`scene_judgment`、`editorial_review` |
| 平台实质差异 | 六套结构、语气、默认篇幅、图数目标、行动邀请；抖音图文轮播、B站专栏图文 | `services/api/src/agent/platformStrategies.cjs` |
| 事实可回查 | 事实点关联 E 编号及原文引用；服务端校验引用，数字与价格规则拦截，模型语义审稿 | `facts[].fact_points`、`agentRuntime.cjs` |
| 图文交付 | 同型号本地图片索引、安全图片接口；导语、正文、行动邀请及实际插图；列出文件名、来源、插入位置和图注 | `creativeAssets.cjs`、`apps/web/src/lib/creativeArticle.js` |
| 四部分统一输出 | 对话与完整 MD 下载呈现场景判断、知识库依据、图文软文、核验结果；复制只取文章 | `creativeReport`、`ArticleDeliveryTools.jsx` |
| 缺证据或冲突 | 无可用产品资料、发现冲突、没有同型号配图时停止文章交付；不会用模板假装成功 | `result_type: blocked`、`validation` |
| 连续交互 | 澄清与改稿直接在对话中完成；保留当前稿与历史，普通问答不触发整篇重写 | `history`、`last_artifact`、意图分流 |

## 验证和边界

自动化回归覆盖来源隔离、图文位置与统一输出、错误拦截、冲突停止、审稿重写上限和会话衔接。真实模型验收脚本为 `scripts/smoke-illustrated-copy.cjs` 与 `scripts/smoke-agent-conversation.cjs`。具体运行结果应以本次实际日志为准。

本轮验证：35 项自动化测试通过，前端生产构建成功。真实调用产生过小红书四图、朋友圈单图输出，但同时暴露引用/响应结构不稳定及无依据护眼推断；已加入引用编号解析、成功审稿空列表兼容与护眼承诺规则拦截。整套真实模型多轮验收尚未全通过，不能标记为全部达标。此前模型审稿通过不代表相关健康效果已经核实。

事实引用校验不等于证明所有陈述正确，冲突识别和语义审稿仍依赖模型。图片目前仅按索引匹配型号，未执行视觉核验、自动裁切或版权授权核验，输出会保留待人工确认项。平台图数受素材数量和用户上限约束，不能借用其他型号补齐。Markdown 图片依赖本地服务，不是独立离线图片包。平台与场景质量需要通过多组真实样例持续评价，不能仅凭提示词声称已达到全部评审质量标准。
