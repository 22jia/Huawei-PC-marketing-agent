# 平台编辑与创作灵感

流程：读取需求 → 搜索近期表达 → 核对来源和发布时间 → 按平台、人群与产品适配筛选 → 展示最多五个切入点 → 用户选择或跳过 → 基于产品证据创作。

小红书先确定独立成立的生活经验或姿态，再让产品承接这种偏好；公众号先提出可讨论的判断，明确理由关系及证据边界。策划、写作、审稿共享平台编辑规则。

事件话题要求与产品或当前人群需求直接相关；表达玩法筛选含义是否可迁移、语境是否合适、改编是否自然，原来源无须提及电脑。美食事件不当然适合电脑，但其表达结构可以自然转译。

标签由程序判定，不采信模型自报热度：
- 近期表达参考：来源页面 article:published_time 可核对，处于过去30天内，未确认传播规模。
- 热门梗：在上述基础上，还需带来源链接的已核实平台榜单或互动数据。
- 表达参考（时间待核实）：日期未知、抓取失败或时间超出窗口；不得称最近很火。

当前公开搜索接入会尝试核对文章发布时间，但尚未接入表达级传播数据核验，因此一般不会输出热门梗。搜索摘要、转载数与抓取时间均不能替代传播证据。候选是原创改编方向，不是已经发生的亲测或产品参数。
