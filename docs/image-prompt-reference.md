# 生图提示词与样例记录

## MateBook 14（鸿蒙版）商业海报

用户提供的参考指令：

> 生成一张高级商业产品宣传海报，产品为 HUAWEI MateBook 14（鸿蒙版），品牌名为华为。整体采用现代、极简、高级的科技商业广告风格，画面搭配同色系深浅变化和少量白色文字。产品作为画面核心主体，使用高质量 3D 写实渲染，材质细节真实，带柔和反光和高级棚拍光影。产品可轻微悬浮，底部带自然阴影，突出立体感。版式采用简洁对称构图，背景加入超大英文排版，与产品形成前后层次。四周可以加入少量极简 UI 线条、几何装饰和产品参数信息，但不要过度复杂。整体要有高端电子品牌广告、Behance 商业视觉、产品发布会海报的质感。字体使用简洁现代无衬线字体，排版克制，留白充足。底部加入简洁 CTA 按钮，例如“EXPLORE NOW”，以及少量品牌官网或社媒信息。画面要求高级、干净、商业感强、真实产品广告质感、超高细节、电影感灯光、专业产品摄影效果。

## 2026-10-22 样例观察

- 三次试验结果均出现蓝色山水湖面，即使原始指令没有山水。
- 一次结果保留了官方素材周围的白色矩形；另一次素材透明、呈现斜侧视角；第三次是正面开合视角。
- 本地把品牌、型号、MATEBOOK 大字和 CTA 合成到画面上。官方产品主体取自下拉框选中的单张素材，不由模型重画。

## 诊断

- 当时 `buildPrompt` 对商业海报固定注入 blue mountain-and-lake 场景，并且没有把用户视觉描述传给模型。这解释了山水为何覆盖原 prompt。现已改为传递用户描述并明确禁止引入未请求的场景元素。
- 白色矩形不是模型新画的白板，而是选中官方原图的背景；不透明图片没有透明蒙版时，确定性合成会保留整张图片。透明 PNG 才能只合成电脑主体。
- 产品角度与屏幕内容由所选素材文件决定。不同素材有不同视角与屏幕画面，连续试验只有固定选择同一个文件，才能对比 prompt 的影响。
- “3D 写实渲染”和对产品打棚拍光属于重绘/编辑主体的要求。当前安全路径保留官方像素作为唯一主体，模型只生成空背景，因此不会执行这部分 prompt；可以让背景具备高级棚拍光感，但无法真实地重打产品光或改变悬浮姿态。
- 目前 CTA、品牌和型号是本地排版；不应声称模型逐句执行了整段 prompt。用户描述控制背景氛围，程序负责已实现的版式和本地文字，官方素材决定产品外观。
