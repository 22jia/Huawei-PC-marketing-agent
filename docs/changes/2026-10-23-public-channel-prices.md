# 自动公开查价（2026-10-23）

推荐卡片通过 shared/recommendationCopy.mjs 呈现场景收益，去掉原始任务标签及重复“适合”清单。参数引用产品事实，场景匹配引用卖点与限制，活动引用价格卡；复用软文 MarkdownContent 的引用角标跳转知识库。历史卡片在显示时也使用同一格式。

比价面板打开和配置切换时先显示本地历史参考，再自动读取官方商品页和教育专区。所选系统、内存/硬盘/柔光版、颜色、CPU及键盘必须匹配后，公开售价才自动参与比较。划线价、配件价和教育专区起售价不作为该配置成交价。

后端使用 playwright-core 驱动独立无头浏览器，处理商城的 Cookie、重定向和动态 SKU。Windows 默认发现 Edge/Chrome；Linux 安装 Chromium，或通过后端 PRICE_BROWSER_EXECUTABLE 指向浏览器可执行文件。部署前在 services/api 执行 npm ci。无需用户打开或登录浏览器。

查询按商品与配置合并重复请求，成功结果缓存 2 分钟，串行限制浏览器资源使用。每次采集最多 45 秒，缓存保留原始查询时间，失败结果不缓存。价格与来源、已选配置、查询时间和失败原因写入现有 data/run-logs 请求日志，阶段 channel_prices.public_lookup。

教育专区已收录但无法取得同配置明确优惠金额时，展示“优惠金额未取得”。官方横幅说明认证后享优惠，并不能证明公开价格必须认证后可见；删除教育价手填及个人账号价格确认。勾选教育资格后显示已记录及金额尚未取得的原因，不编造折扣。

勾选国补个人资格后，按已核实商城售价即时展示“国补条件试算”：5899 元减 884.85 元，预计 5014.15 元。取消勾选恢复公开原价。金额按分计算、最高减 1500 元，规则过期或未取得可靠公开售价时不试算。当地活动覆盖、商品一级能效与参与条件尚未查明时，试算不计入已核实最低价，并显示剩余适用条件。

验证：node --test tests/demo-store-plan.test.cjs tests/channel-prices.test.cjs tests/vmall-public-price.test.cjs；apps/web 下 npm run build。真实官方查询验证 MateBook 14 鸿蒙版 16GB/512GB ¥5899、24GB/1TB/柔光版 ¥8399（以实际查询时间为准）。

## 比价面板精简与核算标准

删除重复的型号、预算填写表单；配置选择移到价格卡片上方，切换后自动查价并保留个人资格。预算继承对话，展示当前售价或条件试算与预算的差额。商城历史价格不再标为门店参考基准。

删除重复价格表，改为“核算标准与当前算式”：同款同配置匹配、适用优惠不重复扣减、国补按补贴前价格的15%且封顶1500元并四舍五入到分、实际渠道比较需有效门店报价。尚未核实的地区及商品参与条件不进入确定最低价结论。

页面实测：6000元预算、5899元公开价、勾选国补显示5014.15元与预算差额985.85元；无重复型号/预算输入或价格表，浏览器无运行错误，前端生产构建通过。
