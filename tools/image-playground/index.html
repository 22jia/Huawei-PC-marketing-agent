第一次使用：如何配置 Key

在仓库根目录创建 .env.image-playground，写入：

CREDIT_MEDIA_API_KEY=你的黑客松Key
REMOVE_BG_API_KEY=你的remove.bgKey
IMAGE_TIMEOUT_MS=120000

图片 Key 用于生图；remove.bg Key 用于将不透明官方产品图去背景。请在 remove.bg 获取独立 Key 并确认账户额度。两个 Key 都只保存在本地服务端，不要填入画面描述或提交到 Git。

保存后重启测试服务。产品合成还需要在终端运行：

npm install --prefix services/api

如果没有配置抠图 Key，带背景的官方图会停止并显示原因，不会再以白底方块冒充抠图结果。已透明素材无需该 Key。
